# سوقنا SOUQNA — تقرير جاهزية الإطلاق التجريبي

تاريخ المراجعة: 19 تشرين الثاني/نوفمبر 2026

## المنفذ في مستودع التطوير

- سوق إلكتروني للسويداء مع إعلانات متعددة الصور، روابط فيديو، تصنيفات ومتاجر متعددة مستقلة الاشتراكات لكل حساب.
- إدارة العملاء والإعلانات والمتاجر والمدفوعات اليدوية مع تأكيد استلام المال وحفظ سجل النجوم.
- صلاحيات المشرفين على الوظائف والعيادات المناوبة ومحطات الوقود.
- حذف إعلان وصوره من خلال وظيفة خادمية موثوقة وسجل لإعادة تنظيف الصور الفاشلة.
- تمييز مدفوع بتاريخ انتهاء قابل للتجديد، مع ظهور الإعلان في أعلى النتائج خلال فترة التمييز، وإزالة الأولوية دورياً من الواجهة بعد انتهائها.
- منطق نشر مميز إلى Facebook/Instagram يبدأ فقط بعد موافقة المدير وتفعيل الاشتراك، مع منع المنشورات المكررة عند التجديد.
- خدمة Meta Graph API ومنسق فحص انتهاء المنشورات موجودان ككود، لكن الربط والمشغلات غير مفعّلين ولم تُنشأ صفحات Meta بعد.
- حالة المنشورات متاحة للمدير دون كشف رموز Meta أو معرّفات المنشورات.
- طقس السويداء، آلة حاسبة بسيطة وأخرى متقدمة، وصرف عملات دولي مرجعي، ومؤشر الذهب العالمي مع المصدر وتاريخ التحديث.
- خدمة PWA تعمل جزئياً دون إنترنت، بما فيها ملفات الحاسبة بعد تحميلها.

## التمييز بين الأسعار العالمية والمحلية

التحويل الدولي يعرض أسعار صرف مرجعية يومية ولا يمثّل سعر الصرف الموازي السوري أو أسعار محال الصرافة. الذهب يعرض سعر الأونصة العالمية بالدولار والتقدير النظري لجرامات 24/21/18 قيراط، وليس سعر محلات الذهب المحلية في السويداء. للحصول على أسعار بيع وشراء سورية فعلية لا بد من مصدر محلي موثوق بحقوق استخدام مناسبة وتحديث مستمر.

## متطلبات لا تزال خارج قدرة الاختبارات البرمجية

1. تدقيق الخدمات الفعلية في مشروع souqna-staging عبر أمر القراءة فقط: npm run audit:staging:read-only، بعد تسجيل الدخول إلى حساب Google المخول.
2. الحصول على موافقة صريحة قبل نشر Cloud Functions أو تفعيل فوترة Firebase أو أي وظيفة مجدولة.
3. نشر قواعد الأمان والوظائف على Staging فقط بعد التدقيق؛ مشروع الإنتاج souqna-sweida يبقى دون تعديل.
4. إنشاء صفحة سوقنا الرسمية على Facebook وحساب Instagram Professional وربطهما وتأكيد صلاحيات Meta للنشر والحذف.
5. حفظ مفاتيح الوصول على الخادم حصراً، وفحص النشر والحذف فعلياً على صفحات مملوكة لسوقنا قبل تفعيل الخاصية للعملاء.
6. مراجعة ترخيص Open-Meteo عند الاستخدام التجاري، وشروط نسب البيانات والتخزين المؤقت لخدمة ExchangeRate-API.
7. فحص المتصفح على أجهزة فعلية قبل إطلاق نسخة تجريبية عامة.

## أوامر التحقق داخل المستودع

    npm install
    npm install --prefix functions
    npm test
    npm run test:release

تغطي الاختبارات الحالية بيئات Firebase Emulator مستقلة، وقواعد الأمان، والمدفوعات التجريبية، وتحليل الصور، ومكونات الواجهات. لا تعني نتائجها أن مشروع Staging الفعلي قد نُشر أو فُحص خارج المحاكيات.
