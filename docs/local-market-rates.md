# أسعار السويداء في سوقنا — تشغيل تجريبي

## الحقول المتاحة

يعرض سوقنا ست خانات مستقلة: الدولار الرسمي (نشرة مصرف سورية المركزي)، الدولار في السوق غير الرسمية بالسويداء، الذهب عيار 24 و21 و18 للغرام، الفضة عيار 999 للغرام.

كل خانة تحتوي سعر شراء ومبيع بالليرة السورية **الجديدة**، اسم المصدر، رابط المصدر إذا توفر، ووقت المعلومة بتوقيت دمشق. **كل 1 ليرة جديدة = 100 ليرة قديمة** في إصلاح العملة لعام 2026؛ يُرفض استخدام وحدة العملة القديمة داخل قاعدة الأسعار لتجنب خلط الأرقام.

لا توجد قيم افتراضية مخترعة: عند غياب إدخال موثّق يظهر "لم يُنشر سعر موثوق لهذه الخانة بعد". عندما يصبح سعر السوق أقدم من 24 ساعة تظهر علامة بيانات قديمة؛ سعر النشرة الرسمية يُعلّم كقديم بعد 72 ساعة، لأنها قد لا تصدر أيام العطل. لا يُصف أي رقم قديم بأنه سعر حي.

## المشرف اليومي

1. أنشئ حساب المستخدم عبر Firebase Authentication (بريد وكلمة مرور).
2. يمنح المدير الدور moderator لحسابه في users/{uid} وفق إجراءات الإدارة الحالية.
3. من شاشة إدارة مشرفي الخدمات، أضف UID إلى staffAssignments/{uid} وحدد **أسعار الدولار والذهب والفضة** فقط (market_prices)، وفعّل الحساب.
4. يدخل المشرف إلى نسخة souqna-staging التجريبية، ويفتح "إدارة الأسعار" أسفل لوحة أسعار السويداء.
5. يختار الخانة، ويدخل سعر الشراء والمبيع في الليرة الجديدة، واسم المصدر، ورابط النشرة الرسمية للدولار الرسمي، ووقت القراءة، ثم يحفظ.
6. تتحقق قواعد Firestore من جميع الحقول ومن صلاحية الدور والقسم وقت الكتابة. عند تعطيل صلاحية المشرف تتوقف قدرته على تحديث الأسعار فوراً.

المسار: localMarketRates/{id}. السجلات قابلة للقراءة العامة في Staging، وتُقبل كتابة manual حصراً من المدير أو مشرف الأسعار المفعّل. يتم حفظ updatedAt بتوقيت الخادم وupdatedBy بمعرّف المشرف. لا يمكن للمشرف حذف السجل أو منح نفسه صلاحيات إضافية.

## مصادر الربط التلقائي المستقبلية

لم يُعتمد مزود API تجاري بعد. قبل تفعيل التحديث الآلي يجب التحقق من: موثوقية أسعار السويداء المحلية (وليس المتوسط الوطني)، وكونها أسعار شراء/مبيع، ووضوح الوحدة الجديدة/القديمة، ودقة توقيت المصدر، وشروط إعادة النشر وحقوق الاستخدام التجاري، وسعر الاشتراك وإتاحة API مستقرة.

مصادر للاستطلاع فقط ولا تمثل موافقة على استيراد بياناتها:
- https://api.exchanger.sy/ar/docs
- https://lirascope.syria-cloud.sy/ar/api-docs
- https://allira-sy.com/data-api
- https://price.sy/

في حال اعتماد مصدر، يُفضّل موصل خادمي ذو مصادقة ومعدل استدعاء محدود، مع حفظ قيمة المصدر ووقت التحديث لكل خانة، لا صفحة HTML تُجمع بياناتها خلسة. لا تضع أسرار API في ملفات الويب أو بيانات Firestore العامة. يتطلب نشر موصل آلي أو جدول سحابي موافقة المالك وتدقيق التكاليف والحقوق.

## خصوصية البيئة

- المشروع التجريبي فقط: souqna-staging.
- تحديث القواعد في الملف firestore.staging.rules فقط؛ لم يتم تعديل firestore.rules أو نشر أي منهما.
- لا كتابة ولا نشر إلى souqna-sweida.
- لا Cloud Functions ولا مفاتيح Service Account ولا فوترة.
- اختبارات المحاكي: npm run test:market-prices.
- اختبارات الكود: npm run test:unit.
