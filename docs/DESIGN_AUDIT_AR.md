# سوقنا — تدقيق تطابق التصميم مع المعاينة المعتمدة

المصدر التصميمي: ملف المستخدم **souqna-news-premium-preview.html** (معاينة تفاعلية محلية في المكتبة، وليست تطبيقاً متصلاً بـ Firebase). الملف يحتوي قائمة جانبية كحلية، شريط بحث علوي أبيض، شريط أخبار متحرك، بانر رئيسي مدفوع، بطاقات فئات ومتاجر، وأقسام للحساب والمفضلة والنجوم والإدارة.

## أولويات التصميم التالية

1. تنفيذ صفحة المفضلة وربطها بكل مستخدم بقواعد Firestore خاصة وآمنة.
2. تحسين البنر المدفوع بصور أكبر، وأزرار الانتقال، وحالات عدم وجود إعلانات، مع الالتزام بتاريخ انتهاء الاشتراك.
3. توحيد البحث بين الإعلانات والمتاجر وإضافة فلاتر أسعار ومناطق.
4. ضبط تصميم لوحة الإدارة ليطابق إحصاءات المعاينة، مع بيانات حقيقية لا أرقام تجميلية.
5. مراجعة صور المنتجات والمتاجر والأيقونات الكريستالية قبل تثبيت الهوية النهائية.
6. التحقق من قراءة الشاشة والألوان والتباين والوصول بلوحة المفاتيح، وبدء التشغيل على هاتف Android فعلي.
7. مراجعة استهلاك Firestore لصور Base64 ونقل الوسائط إلى Object Storage ضمن خطة تسعير وحماية.

## حدود الادعاء

- الملف التصميمي المعتمد **نموذج UI**؛ لا يجوز استبدال تطبيق Firebase الحي به مباشرة أو وصفه بأنه تطبيق مكتمل.
- تطبيق GitHub الحالي **برمجياً حقيقي**، لكنه لا يطابق النموذج بنسبة 100%.
- الصور والبيانات في اختبارات Chromium تجريبية، ولا تثبت تشغيل قاعدة بيانات الإنتاج.
- أي تصميم مالي يجب أن يوضح أن تأكيد الدفع يدوي وليس اتصالاً بنكياً مباشراً.
- يجب إكمال المهام المذكورة ومراجعة النتائج بصرياً قبل اعتبار التصميم نهائياً.
